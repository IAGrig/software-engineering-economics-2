# Организация репозитория

Основная ветка — main. Изменения по задачам выполняются в отдельных ветках:

- feature/TRELLO-N-description — новая функциональность;
- fix/TRELLO-N-description — исправления;

Сообщение связанного коммита начинается с идентификатора задачи TRELLO-N.

Стандартный маршрут: К выполнению → В работе → Ревью → Тестирование → Готово.
